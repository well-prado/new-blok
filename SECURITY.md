# Security policy

This repository is in pre-alpha development and has no supported production release. Supported version and disclosure response policies will be published before the first release candidate.

Please use [GitHub private vulnerability reporting](https://github.com/well-prado/new-blok/security/advisories/new) for vulnerabilities. Include a synthetic reproduction, affected commit/version, expected boundary, and observed impact. Do not place secrets, customer payloads or exploit credentials in public issues.

Native Go nodes are trusted application code. Worker isolation, capability manifests, telemetry redaction and approval enforcement each have different guarantees; see the architecture and owning roadmap issues.
